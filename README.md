# Plan Maestro

Proyecto web con:

- `backend`: API en Node.js + Express + SQL Server.
- `frontend`: interfaz HTML/CSS/JS consumiendo la API.

## Ejecutar

1. Instalar dependencias del backend:
   - `cd backend`
   - `npm install`
2. Configurar `backend/.env` (ver `backend/.env.example`).
3. Desde la raiz del proyecto:
   - `npm run dev`
4. Abrir:
   - `http://localhost:3000`

## Nota sobre frontend

El frontend esta preparado como app web clasica. No usa Expo ni React Native.
